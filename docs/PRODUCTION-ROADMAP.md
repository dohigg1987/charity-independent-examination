# Production roadmap

## Release 1: controlled prototype, included

- Practitioner portfolio and engagement workspace
- Complete CC32 Direction structure
- Workpaper procedures, conclusions, comments and status controls
- Client evidence request and upload experience
- Review centre and completion gates
- Eligibility rule tests and enterprise domain model

## Release 2: operational service

- Identity provider, MFA, session controls and invitation lifecycle
- PostgreSQL persistence with row-level tenant policies
- Encrypted object storage with presigned uploads and malware scanning
- Email notifications and request reminders
- Server-enforced workflow transitions, versioning and audit events
- DOCX and PDF report assembly from controlled templates
- Charity Commission public-register integration and monitored guidance versions

## Release 3: assurance and scale

- Independent penetration test and remediation
- UK GDPR data protection impact assessment and retention automation
- Backup restoration, incident response and business continuity exercises
- Practice-wide templates, sampling, analytics and quality-control reviews
- Accessibility audit against WCAG 2.2 AA
- Security and operational evidence suitable for Cyber Essentials Plus and ISO 27001 alignment
